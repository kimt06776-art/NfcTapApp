# nfctapapp Color System

## 1. Color Philosophy

nfctapapp의 컬러는 감정을 자극하거나 위로하기 위한 것이 아니다.  
이 컬러 시스템의 목적은 **사용자가 하나님 앞에 설 수 있는 ‘공간’을 만드는 것**이다.

- 컬러는 주인공이 아니다
- 컬러는 메시지를 설명하지 않는다
- 컬러는 텍스트와 침묵을 지탱하는 바닥이다

> Design principle:  
> **Do not comfort emotions. Create space for presence.**

---

## 2. Core Color Palette (Fixed)

### Base / Background
- **Name:** Stone Gray
- **Hex:** `#7B7A77`
- **Usage:**
  - Home background (primary)
  - Default screen background
  - Neutral surfaces

- **Meaning:**
  - Grounded
  - Neutral
  - Non-emotional
  - “Space” rather than “scene”

---

### Depth / Ground
- **Name:** Deep Stone
- **Hex:** `#4F4E4B`
- **Usage:**
  - Bottom area of Home
  - CTA landing zone
  - Visual grounding
  - Gradient depth

- **Meaning:**
  - Stability
  - Weight
  - Resting place for actions

---

### Subtle Warmth / Presence
- **Name:** Hidden Warm
- **Hex:** `#9A8F7A`
- **Usage:**
  - Very subtle accents only
  - Divider lines
  - Micro UI hints
  - NEVER primary buttons or highlights

- **Rules:**
  - If the color is noticeable, it is overused
  - Presence should be felt, not seen

---

## 3. Text Colors

### Primary Text
- **Hex:** `#F5F4F2`
- **Usage:**
  - Scripture
  - Core messages
  - Main content

- **Note:**  
  Avoid pure white (`#FFFFFF`).  
  Pure white breaks the sense of space and feels artificial.

---

### Secondary Text
- **Hex:** `#D8D6D2`
- **Usage:**
  - Supporting sentences
  - Explanatory lines
  - Subtle guidance text

---

### Tertiary / UI Text
- **Hex:** `#C1BFBB`
- **Usage:**
  - Icons
  - X button
  - Non-primary UI elements

- **Rule:**
  - UI should exist without demanding attention

---

## 4. Gradient Rules

### Home Background Gradient
- Direction: Top → Bottom
- Colors:
  - Top: `#7B7A77`
  - Bottom: `#4F4E4B`

- Behavior:
  - Extremely subtle
  - No visible color banding
  - No directional storytelling

- Animation (optional):
  - Very slow brightness shift
  - 10–15 seconds per cycle
  - No hue change

---

## 5. Strict Prohibitions

The following are **not allowed** in nfctapapp:

- Pure white backgrounds
- High saturation colors
- Emotional warm browns
- Gold or symbolic religious colors
- Color-coded emotional states
- Bright CTA buttons
- Color-based emphasis on scripture

If color begins to explain meaning, the design has failed.

---

## 6. Design Test Checklist

Before approving any UI using these colors, confirm:

- [ ] Does this color create space rather than emotion?
- [ ] Does text remain the visual priority?
- [ ] Can this screen be used daily without fatigue?
- [ ] Does the UI feel neutral, calm, and grounded?
- [ ] Would removing this color improve clarity?

If unsure, simplify.

---

## 7. Summary

nfctapapp uses color not to decorate faith,  
but to **step aside so faith can happen**.

Color exists to support presence, not performance.
